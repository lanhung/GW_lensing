# Data products

Large data products are not stored in Git. They are regenerated by the scripts below (fixed
seeds) or obtained from the authors.

## v2 catalogues (`data/v2/`)

`gwlens.catalogue` writes one Parquet table per lens family plus a JSON sidecar recording the
observation model, the distance-error calibration and the number of selected pairs per scenario.

| Family | Lens systems | Generation seed |
| --- | --- | --- |
| SIS | 250 000 | 20261016 |
| SIE | 250 000 | 20261016 |
| SIE_shear | 150 000 | 20261016 |
| EPL_shear | 150 000 | 20261016 |

Column groups:

* `true_*` — simulation truth (source and lens parameters); never used as model inputs.
* `obs_*` — scenario-independent follow-up measurements (redshifts, velocity dispersion, lens light).
* `<scenario>__selected` — the system passes the detection, observing-window and resolvability cuts.
* `<scenario>__obs_*` — GW measurements (SNRs, relative magnification, apparent distances, delay).
* `<scenario>__geo_*` — image positions of the GW pair relative to the observed lens centre, number
  of resolved images and radii of additional images.
* `<scenario>__true_*` — truth for the selected pair (magnifications, Morse indices, convergence).

Scenarios: `O5` (A+ H1/L1, AdV V1) and `ET` (ET-D triangle).

## Real-data inputs (`realdata/outputs/`)

| File | Source | Script |
| --- | --- | --- |
| `gwtc_bbh_events.csv` | GWOSC event API, GWTC-1, 2.1, 3 and 4.0 confident BBHs | `calibrate_distance_errors.py` |
| `distance_error_calibration.json` | fit of sigma_lnD versus network SNR | `calibrate_distance_errors.py` |
| `gwtc4_bp2p_summary.json` | GWTC-4.0 population paper source (arXiv:2508.18083) | `fetch_gwtc4_population.py` |
| `o4a_injections.csv`, `o4a_injection_summary.json` | injections into GWOSC O4a 4 kHz H1/L1 strain | `o4a_injections.py` |

The O4a strain files are downloaded to `realdata/o4a_cache/` (ten files, about 1.3 GB) and are
not redistributed.

## v1 data

The original selected-SIS catalogue (2500 events, seed 238) and four-family benchmark are
regenerated with `SIS_GW_physics_baseline.py` and
`experiments/extended_experiments/generate_universal_latent_benchmark.py`.
